Pitwall Agent — endurance stint planner

Compare fuel, tyre, driver-rotation and pit-stop strategies before your endurance race.

A local-first, terminal-based strategy tool for sim racers, team captains, and race-day operators. Free and open-source. Optional local AI routes plain language; deterministic tools own the race facts.

MIT licensed · Python 3.11–3.14 · Core planning works offline after installation · No account, API key, or data upload.

What problem it solves

Planning an endurance race is overwhelming — fuel reserves, tyre changes, driver rotations, Safety Car timing. Pitwall Agent turns those variables into a clear, auditable plan you can take to race day. Every number comes from a deterministic engine you can inspect, trace, and rerun.

How the numbers stay auditable

Deterministic engine — never AI-guessed

All fuel, tyre, and driver maths is deterministic Python code in engine/. You can read every line and re-run it for the same result.

AI routes; local tools answer

An optional local Ollama model can route plain language into an allowlisted tool. Final race facts are rendered locally from a successful deterministic result; failed or unknown calls cannot ground an answer.

Evidence Levels A / B / C

Each result states its input source, evidence level, confidence, assumptions, and warnings.

Local-first, no telemetry upload

Your CSVs, race config, and reports stay in a visible .pitwall/ folder on your own machine. Nothing is uploaded anywhere.

Honest alpha statement. Pitwall Agent is alpha software. All bundled examples are synthetic (Evidence Level C), and no real-session case study has been published. The Ollama integration is real, but there is no published real-model conformance benchmark; direct deterministic commands remain the recommended operational path.

What it does today

Fuel & stint planning

Stint lengths, fuel loads, and exact fuel additions per stop.

Tyre life & changes

Tyre sets, age at stint end, and change planning per stop.

Driver rotation

Stable driver identities and configured drive-time rule checks.

Strategy comparison

Conservative / Balanced / Fuel Save ranked side by side.

P10 / P90 uncertainty

For projected laps, P10 is the fewer-laps case and P90 the more-laps case. Raw lap-time percentiles reverse because fewer seconds is faster.

Telemetry CSV ingest

Column mapping, outlier checks, and evidence calibration from your laps.

Safety Car what-if

One declared pre-race scenario with explicit multipliers. Pre-race only.

Strategy trigger cards

Pre-agreed HOLD / RECONSIDER thresholds to take to the pit wall.

Markdown pit sheet

One scannable page to print or keep open on race day.

Machine-readable JSON

--json on the commands you script or pipe into your own tools.

Optional local AI

Ollama on loopback only, for plain-language routing. Final race facts remain deterministic, and everything works without AI.

No live data, no lock-in

No live timing, no proprietary APIs, no accounts, no tracking.

Install

GitHub-only alpha. Pitwall Agent is not published on PyPI. The main-branch source ZIP contains the current unreleased alpha.2 hardening; no alpha.2 wheel exists yet. The published alpha.1 wheel predates these fixes. The core install never downloads Ollama or an AI model.

Windows — easiest

# 1. Install Python 3.11–3.14 from python.org
# 2. Download the source ZIP linked below
# 3. Choose Extract all
# 4. Double-click run.bat

Download the source ZIP. The launcher creates a private environment, runs a health check, and opens Pitwall.

Linux / macOS

git clone https://github.com/Dabi-init/endurance-stint-planner.git
cd endurance-stint-planner
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .
pitwall doctor
pitwall init --guided
pitwall compare

Package size and releases

A wheel built from the current alpha.2 source is approximately 89 KB. It is not published yet; do not treat the older alpha.1 wheel on the GitHub releases page as equivalent. The release process will attach a versioned alpha.2 wheel after this hardening is merged and tagged.

Measured disk footprint

In a clean Windows/Python 3.14 audit, Pitwall's installed files used about 830 KB, the complete private virtual environment used about 27.4 MB, and an extracted source copy plus its launcher-created environment used about 28.0 MB. The launcher's isolated two-run test retained 0 bytes in its pip-cache directory. A Git clone also retains Git history; totals vary by Python and operating system. App imports are capped at 10 MiB and 50,000 rows per CSV, with 100 MiB total telemetry storage. Reports and validations are capped at 2 MiB each, 25 MiB combined, and 500 files.

Choose your model storage. Every deterministic feature works with no AI. Core-only uses 0 GB of model storage; no Ollama install or model opt-in is required.

  • Core only: keep AI off, or clear a previous selection with .\.venv\Scripts\python.exe -m pitwall model off.
  • Provisional first try: qwen3:8b, approximately 5.2 GB of model storage.
  • Smaller unverified candidate: qwen3:4b, approximately 2.5 GB of model storage.
# Provisional first model to try
ollama pull qwen3:8b
.\.venv\Scripts\python.exe -m pitwall model use qwen3:8b

# Smaller unverified candidate
ollama pull qwen3:4b
.\.venv\Scripts\python.exe -m pitwall model use qwen3:4b

pitwall model recommend runs a read-only deterministic core self-check and prints these Ollama-only choices. It never contacts Ollama, downloads a model, creates a workspace, or changes configuration. Core-only is the verified operational path; both model candidates remain unverified until Pitwall publishes a real-model tool-calling conformance benchmark.

Pitwall never downloads a model automatically. Model sizes exclude Ollama and its caches. Ollama's Windows installation requires at least 4 GB, so the 8B setup needs roughly 9.2 GB or more. Remove an opted-in model with .\.venv\Scripts\python.exe -m pitwall model off followed by ollama rm qwen3:8b or ollama rm qwen3:4b; uninstall Ollama separately if you no longer need it.

Alpha status and limitations

Read this before you rely on it for a real event.

  • Alpha software — not production-validated.
  • No real-session case studies yet. Every bundled example uses synthetic data.
  • Safety Car support is a pre-race what-if only — it is not live race control.
  • No live timing, no competitor prediction, no proprietary telemetry APIs.
  • Ollama is optional and never auto-downloaded — every deterministic feature works with no AI at all. Model recommendations are provisional until a real-model conformance benchmark is published.
  • Evidence Level C means the numbers came from preset or synthetic assumptions, not measured data.
  • Sporting regulations are your responsibility. Pitwall Agent checks the rules you configure, not any official rulebook.

Build your endurance race plan, lap by lap — deterministically.

What problem it solves

Planning an endurance race is overwhelming — fuel reserves, tyre changes, driver rotations, Safety Car timing. Pitwall Agent turns those variables into a clear, auditable plan you can take to race day. Every number comes from a deterministic engine you can inspect and trust.

Why you can trust the numbers

Deterministic engine — never AI-guessed

All fuel, tyre, and driver maths is deterministic Python code in engine/. You can read every line and re-run it for the same result.

AI is an explainer, not a decision-maker

An optional local Ollama model can explain the plan in plain English. It cannot invent, change, or own the race mathematics.

Evidence Levels A / B / C

Every input is labelled with its source and confidence, so you always know whether a number came from telemetry or from an assumption.

Local-first, no telemetry upload

Your CSVs, race config, and reports stay in a visible .pitwall/ folder on your own machine. Nothing is uploaded anywhere.

Honest alpha statement. Pitwall Agent is alpha software. All current case studies use synthetic data (Evidence Level C). No real-session validation has been published. We are honest about what we know and what we don't.

What it does today

Fuel & stint planning

Stint lengths, fuel loads, and exact fuel additions per stop.

Tyre life & changes

Tyre sets, age at stint end, and change planning per stop.

Driver rotation

Stable driver identities and configured drive-time rule checks.

Strategy comparison

Conservative / Balanced / Fuel Save ranked side by side.

P10 / P90 uncertainty

Pessimistic and optimistic bounds, not a single false-precision number.

Telemetry CSV ingest

Column mapping, outlier checks, and evidence calibration from your laps.

Safety Car what-if

One declared pre-race scenario with explicit multipliers. Pre-race only.

Strategy trigger cards

Pre-agreed HOLD / RECONSIDER thresholds to take to the pit wall.

Markdown pit sheet

One scannable page to print or keep open on race day.

Machine-readable JSON

--json on the commands you script or pipe into your own tools.

Optional local AI

Ollama on loopback only, for explanation. Everything works without it.

No live data, no lock-in

No live timing, no proprietary APIs, no accounts, no tracking.

Install

Alpha packaging note. pitwall-agent may not be published on PyPI yet. If pip install pitwall-agent cannot find the package, download the wheel from the GitHub releases page and run pip install path\to\pitwall_agent-...whl, or use the developer install below.

Windows

# 1. Download Python from python.org (3.11+)
# 2. Open Command Prompt and run:
pip install pitwall-agent
pitwall doctor
pitwall init
pitwall compare

Linux / macOS

pip install pitwall-agent
pitwall doctor
pitwall init

Developer install (always works)

git clone https://github.com/Dabi-init/endurance-stint-planner
cd endurance-stint-planner
pip install -e .[dev]

Alpha status and limitations

Read this before you rely on it for a real event.

  • Alpha software — not production-validated.
  • No real-session case studies yet. Every published example uses synthetic data.
  • Safety Car support is a pre-race what-if only — it is not live race control.
  • No live timing, no competitor prediction, no proprietary telemetry APIs.
  • Ollama is optional — every deterministic feature works with no AI at all.
  • Evidence Level C means the numbers came from preset or synthetic assumptions, not measured data.
  • Sporting regulations are your responsibility. Pitwall Agent checks the rules you configure, not any official rulebook.
